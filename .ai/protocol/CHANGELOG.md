# AI 研发意图编译与验收协议 · 版本记录

## 1.0.0 — 2026-10-31（首版候选）

- 将自然语言需求、YAML任务契约、JSON回执与逐项真实验收明确分离。
- 建立 Rxxx→ATxxx→Evidence 的可追溯关系，支持结构化验证和 GitHub 持久化。
- 固定 DRAFT/APPROVED/EXECUTING/VERIFIED/BLOCKED 状态与生产操作默认拒绝规则。
- 增加根目录 `AGENTS.md` 快速接管入口、项目上下文、YAML/JSON模板和验证器。
- 引入版本锁定、需求变更请求、反馈建议和协议迭代流程。
- 明确对“100%”的边界：可要求100%必选验收项通过，但不能保证规格无遗漏或软件无隐藏缺陷。

### 待下一轮真实项目实践后检验

- 不同 AI 执行平台是否都能稳定读取并遵守 AGENTS.md 与任务文件。
- 哪些语义歧义仍然导致实现偏差；是否需要新增任务字段。
- JSON Schema 检查与真实 E2E 证据之间仍有什么验收缺口。
- 协议填写与维护成本是否过高；必要时简化而非膨胀。
