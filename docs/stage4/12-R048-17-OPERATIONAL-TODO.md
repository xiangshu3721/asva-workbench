## P1 | 腾讯云主动费用告警

**当前状态：** 仅有日志记录，无主动通知

**待办：**

1. 登录[腾讯云控制台](https://console.cloud.tencent.com/)
2. 进入 **费用中心 → 消息订阅 → 告警配置**
3. 配置以下告警：

| 告警类型 | 产品 | 阈值 | 通知方式 |
|---------|------|------|---------|
| 费用告警 | 云开发 CloudBase | 日消费 > 5 元 | 短信 + 邮件 |
| 资源包用量 | 云开发 | 用量达 80% | 短信 + 邮件 |
| 云函数监控 | asva-api | 执行次数 > 500/小时 | 邮件 |
| 云函数监控 | asva-api | 执行时长 > 60s | 邮件 |
| 云函数监控 | asva-api | 错误率 > 10% | 邮件 |

4. 配置后使用"发送测试消息"验证送达

**验证方法：** 配置后 24 小时内确认收到测试消息

**临时缓解：** 如需紧急暂停，执行：
```bash
curl -X POST $PG_RPC_URL/asva_ai_budget_guard \
  -d '{"request":{"action":"set_control","mode":"DISABLED","actorId":"staff-admin-owner-001"}}'
```

## P2 | 后台任务可靠性优化

**当前状态：** 依赖 SCF Node.js 事件循环，120s 超时内有 PG 保底

**风险：**
- 极端情况下（DeepSeek 长时间超时 + 飞书延迟）可能触及 120s 限制
- 此时 Source 状态保持 UPLOADED，PG 预留已消耗，用户需手动重试

**优化方向：**
- 评估腾讯云 TDMQ/CMQ 消息队列接入成本
- 或独立定时触发器兜底检查 UPLOADED 状态 Source
- 目标：平台级可靠任务投递

**当前可用性：** 已可用，超时场景用户可手动重新保存
