## 实现策略

### 统一适配器架构

```javascript
// 1. 通用分享链接解析(已实现)
parseShareUrl(url) → { reportId, linkSecret }

// 2. 通用报告读取(已实现)
readAssessmentReport(reportId, linkSecret) → report

// 3. 测评特定适配器(需实现)
const adapters = {
  star: { parsePreview, keyMetrics, headline },
  scl90: { parsePreview, keyMetrics, headline },
  pdq4: { parsePreview, keyMetrics, headline },
  ecr: { parsePreview, keyMetrics, headline },
  holland: { parsePreview, keyMetrics, headline },
  // ... 其他测评
}

// 4. 统一导入流程
async function importAssessment(shareUrl) {
  const { reportId, linkSecret } = parseShareUrl(shareUrl)
  const report = await readAssessmentReport(reportId, linkSecret)
  const adapter = adapters[report.assessmentId]
  if (!adapter) throw new Error('不支持的测评类型')
  return adapter.parsePreview(report)
}
```
