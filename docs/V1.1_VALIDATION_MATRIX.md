## 三、数据契约验证

### 3.1 通用报告结构

所有测评报告遵循统一结构:

```javascript
{
  reportId: 'rpt_xxx',              // 报告ID (必填)
  assessmentId: 'star',             // 测评类型 (必填)
  assessmentName: '职业六芒星',      // 测评名称 (必填)
  assessmentVersion: '1.0',         // 版本号 (必填)
  schemaVersion: '1.0.0',           // Schema版本 (必填)
  completedAt: '2026-11-27T10:00:00Z', // 完成时间 (必填,ISO格式)
  nickname: '客户昵称',              // 昵称 (可选)
  reportContent: {                  // 报告内容 (测评特定)
    viewModel: { ... }
  },
  score: { ... },                   // 分数 (测评特定)
  result: { ... }                   // 结果 (测评特定)
}
```

## 四、核心指标展示规则

### 4.1 展示原则

1. **真实数据为准**: 所有指标必须来自原始报告,不自行推断或编造
2. **零分与缺失区分**: 
   - 零分(0): 显示为 "0"
   - 字段缺失: 显示为 "-"
   - 阴性结果: 按各测评规则显示(如SCL-90显示"筛查阴性")
3. **不生成AI分析**: 仅展示原始数据,不提供诊断或建议
4. **保留警示信息**: 如SCL-90危机信号、juying免责声明等

### 4.2 各测评核心指标

| 测评 | 主要指标 | 次要指标 | 展示格式 |
|-----|---------|---------|---------|
| star | 底层动力(3词) | 现实追求(3词)、核心关键词 | 底层动力: X、Y、Z |
| scl90 | GSI、总分、阳性项目数 | 9大因子分 | 总症状指数(GSI): X.XX |
| pdq4 | 筛查类型列表 | - | 筛查提示: X型、Y型 |
| ecr | 依恋类型 | 回避/焦虑维度 | 依恋类型: X型 |
| holland | 主要倾向(RIASEC) | 兴趣代码 | 职业兴趣: X型(R/I/A/S/E/C) |
| loves5 | 主要爱语 | 5种语言得分 | 主要爱的语言: X |
| zhenai | 最薄弱层 | 总分、6维得分 | 最薄弱的一层: X |
| root | 核心能力 | 8维能力分 | 核心能力: X、Y |
| gcd | 电量分数 | 状态档位、耗电维度 | 当前状态: X |
| sefs | 总分 | 最高维度 | 总分: X |
| sensmap | 最敏感维度 | 4维得分 | 最敏感维度: X |
| juying | 总分、分档 | - | 分档: X |
| beattie-* | 总分、等级 | 章节 | 等级: X |
