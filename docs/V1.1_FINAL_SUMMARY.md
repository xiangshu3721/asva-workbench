## 二、技术实现

### 2.1 适配器架构

```javascript
// 统一适配器注册机制
registerAssessmentAdapter(assessmentId, {
  parsePreview(report),  // 生成安全预览
  keyMetrics(report),    // 提取核心指标
  headline(report)       // 生成一句话摘要
})

// 自动识别并路由
const adapter = getAssessmentAdapter(report.assessmentId)
if (!adapter) throw UNSUPPORTED_ASSESSMENT
const preview = adapter.parsePreview(report)
```

### 2.2 数据流

```
导师粘贴H5链接
  ↓
parseShareUrl(链接) → { reportId, linkSecret }
  ↓
readAssessmentReport(reportId, linkSecret) → 原始报告
  ↓
getAssessmentAdapter(assessmentId) → 对应适配器
  ↓
adapter.parsePreview(report) → 安全预览
  ↓
导师确认 → 归档存储
```
