## 变更概要

### 1. 修复「查看原报告」跳转 about:blank
**问题**: 原实现先 `window.open('', '_blank')` 打开空标签，再异步获取链接后导航。浏览器弹窗拦截、异步延迟、跨域策略等原因导致部分场景停留在 `about:blank`。

**修复**: 新增服务端 `/api/assessments/bindings/:id/open-original` 端点，执行：
- 权限校验（导师对客户有权访问）
- 绑定状态检查（仅 ACTIVE 状态可打开）
- 读取加密 shareUrl
- 302 重定向到原始 H5 报告页

前端改为直接 `window.open(openUrl, '_blank')`，服务端完成跳转，无 about:blank 残留。

### 2. 测评卡片增强可视化
新增 `AssessmentCardVisualization` 组件，根据 `displayPayload.kind` 渲染不同测评的增强展示：

| 测评类型 | displayPayload.kind | 展示内容 |
|---------|---------------------|---------|
| 职业六芒星 (star) | `star-hexagram` | 底层动力/现实追求词组 + 关键词标签 |
| Beattie 情绪系列 | `beattie-gauge` | 等级色条 + 总分进度条 + 子维度分项 |
| 主观体验地图 (sefs) | `sefs-radar` | 总分 + Top3 维度 + 维度条形图 |

所有数据来自数据库已存储的 preview，无需外部请求。

### 3. SEFS 主观体验地图数据修复
**问题**: SEFS 适配器原读取路径为 `report.score || report.viewModel`，但实际 H5 报告存储在 `report.reportContent.viewModel`，导致总分为空、最高维度显示"未确定"。

**修复**: 适配器优先读取 `report.reportContent?.viewModel`，兼容旧 `score`/`viewModel` 路径。同时支持 `dimensions` 和 `items` 两种数组格式。

### 4. H5 分享能力判断修正
将 SEFS（主观体验地图）加入 H5 分享能力列表（共 8 种），因其实际存在可导入的 H5 报告页面。

更新前后：
- 7 种 → 8 种 H5 可分享测评
- SEFS 从无 → 有，前端显示「查看原报告」或「补充原报告链接」按钮

### 5. 数据库快照自动补齐展示
新增 `enrichPreviewFromSnapshot()` 服务端函数：在返回列表时，若旧版 preview 缺少 `displayPayload` 但快照完整，自动从快照重新生成 preview，无需导师重新导入。

### 6. 按钮逻辑细化
- H5 能力 && 已存链接 → 显示「查看原报告」
- H5 能力 && 未存链接 → 显示「补充原报告链接」
- 非 H5 能力测评 → 不显示以上按钮
- 保留「更新记录」和「解绑」按钮不变
