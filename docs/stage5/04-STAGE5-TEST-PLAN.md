# Stage 5｜受控测试计划

固定受控 fixtures 覆盖：R0、R1、被动死亡愿望 R2、当前自伤 R3、临近危险 R4、伤害他人、否定表达、第三方表达、历史表达、冲突和 Sparse Unknown。

自动测试至少验证：

- 否定、第三方、历史表达不会被错误归因或直接升级。
- R4/R3/R2 由服务端规则计算，并进入正确 Gate 与商业阻断。
- `UNKNOWN` 不被降级成 R0。
- 未引用 Evidence 的候选信号被丢弃。
- 诊断词、完整身份信息和安全原文不会进入模型上下文/日志。
- fingerprint 幂等和 `STALE` 标记行为可重复验证。

在受控 fixtures 通过前不得连接真实 Production 客户；通过后也只允许使用固定回归样本，不创建高风险 Production 客户。
