# ASVA 心理测评 V1.0.1 优化总结

## 完成的功能

### 1. ✅ 昵称不一致不阻止导入
**后端修改** (`server/index.mjs`):
- 移除 409 错误阻止逻辑
- 改为警告提示，允许导师确认归属
- 保留 `nameConfirmedBy` 和 `nameConfirmedReason` 字段

**前端修改** (`src/App.tsx`):
- 移除 `NAME_MISMATCH_REQUIRES_CONFIRMATION` 错误处理
- 在绑定时直接弹出确认对话框
- 导师确认后自动添加确认信息

### 2. ✅ 查看报告直接在新标签页打开原始测评 H5
**后端修改** (`server/index.mjs`):
- 新增 `GET /api/assessments/bindings/:id/share-url` - 获取分享的完整 URL
- 新增 `POST /api/assessments/bindings/:id/supplement-url` - 补充缺失的分享链接
- 数据库存储 `encrypted_share_url` 字段（包含 linkSecret）

**前端修改** (`src/App.tsx`):
- 将"查看快照"按钮改为"查看原报告"
- 点击后在新标签页打开原始 H5 测评页面
- 如未保存分享链接，提示导师补充

**数据库迁移** (`cloudbase/migrations/20261125200000_asva_assessment_ux_optimization.sql`):
- 添加 `encrypted_share_url TEXT` 列
- 添加 RPC 函数 `get_share_url` 和 `supplement_share_url`

### 3. ✅ 支持同类型测评报告更新，保留更新记录
**后端修改** (`server/index.mjs`):
- 新增 `POST /api/assessments/bindings/:id/update` - 更新/替换当前报告
- 验证新报告类型必须与原报告一致
- 旧绑定标记为 SUPERSEDED，创建新绑定
- 记录更新事件到审计日志

**前端修改** (`src/App.tsx`):
- 添加"更新报告"按钮（仅管理员可见）
- 提示输入新的分享链接
- 更新成功后显示历史记录

**数据库迁移**:
- 添加 RPC 函数 `update_report`
- 自动处理状态转换和事件记录

### 4. ✅ 解绑即从客户档案移除当前报告
**数据库迁移**:
- 修改 `get` action（带 customerId）过滤 `status = 'ACTIVE'`
- 修改 `list` action 过滤 `status = 'ACTIVE'`
- 解绑后报告自动从列表中消失

**前端修改**:
- 更新解绑确认提示文案
- 移除转移和撤销操作入口

### 5. ✅ 移除转移和撤销操作入口
**前端修改** (`src/App.tsx`):
- 移除"转移"按钮
- 移除"撤销"按钮
- 删除 `handleTransfer` 和 `handleRevoke` 函数
- 保留"解绑"功能

### 6. ✅ 心理测评板块放在客户档案正下方
**前端修改** (`src/App.tsx`):
- 将 `<AssessmentPanel>` 从原来的位置（理解面板之后）

  1. Header（客户基本信息）
  2. 一句话理解
  3. 客户档案
  4. **心理测评** ← 移到这里
  5. 理解面板
  6. 更多详细资料

### 7. ✅ 修复重复摘要，优化测评卡片
**前端修改** (`src/App.tsx`):
- 预览卡片移除单独的 `summary` 字段，只保留 `headline`

## 技术细节

### 新增的 Client API 方法
```typescript
getAssessmentShareUrl(actorId, bindingId): Promise<{ bindingId, shareUrl }>
supplementAssessmentShareUrl(actorId, bindingId, shareUrl): Promise<{ success, binding }>
updateAssessmentReport(actorId, bindingId, newShareUrl, reason?): Promise<{ success, binding }>
```

### 数据库变更
- 新增列：`encrypted_share_url TEXT`
- 新增索引：`idx_assessment_bindings_report_id`
- RPC 函数新增 actions：`get_share_url`, `supplement_share_url`, `update_report`
- RPC 函数修改：`get` 和 `list` 现在过滤 ACTIVE 状态

### 权限控制
- 查看原报告：需要导师权限 + 客户访问权限
- 补充分享链接：需要导师权限 + 客户访问权限
- 更新报告：需要管理员权限
- 解绑：需要管理员权限
