**修改文件**: `server/assessment-import.mjs`

**变更**:

- 引入适配器注册机制
- 支持自动识别测评类型
- 统一错误处理

**新流程**:
```
1. 解析分享链接 → { reportId, linkSecret }
2. 读取报告 → report (从 assessmentReportDev)
3. 识别测评类型 → report.assessmentId
4. 获取适配器 → adapter = getAssessmentAdapter(assessmentId)
5. 生成预览 → preview = adapter.parsePreview(report)
6. 返回预览 → 导师确认
```

## 真实数据契约

### 通用报告结构
```javascript
{
  reportId: 'rpt_xxx',
  assessmentId: 'star' | 'scl90' | 'pdq4' | 'ecr' | 'holland' | ...,
  assessmentName: '职业六芒星' | 'SCL-90 症状自评量表' | ...,
  assessmentVersion: '1.0',
  completedAt: '2026-11-27T10:00:00Z',
  nickname: '小明',
  reportContent: {
    // 测评特定内容,由各适配器解析
  }
}
```

### SCL-90 数据结构
```javascript
{
  score: {
    total: 120,           // 总分
    gsi: 1.33,            // 总症状指数
    positiveCount: 35,    // 阳性项目数
    positiveMean: 3.42,   // 阳性症状均分
    negativeCount: 55,    // 阴性项目数
    positive: true,       // 筛查阳性/阴性
    factors: [            // 9大因子
      { id: 'som', name: '躯体化', score: 2.5, level: 'mild' },
      { id: 'obs', name: '强迫症状', score: 3.1, level: 'moderate' },
      // ...
    ],
    crisis: {             // 危机信号(可选)
      level: 'note' | 'urgent',
      title: '危机提示',
      text: '...'
    }
  }
}
```

### PDQ-4+ 数据结构
```javascript
{
```
